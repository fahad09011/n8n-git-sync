# CandidateIQ - Candidate Evaluation Engine

> Automates candidate intake, AI-driven resume evaluation, and interview scheduling for job applications.

---

## Overview

This workflow automates the recruitment pipeline from the moment a candidate submits a job application through to interview scheduling or rejection notification.

When an application is received, the workflow extracts and evaluates the candidate's resume using AI, storing the candidate and application in a database. The candidate's information and evaluation are shared with HR, who decides whether to proceed with an interview.

Depending on the HR decision, the workflow either checks calendar availability and creates an interview invitation with a scheduled event, or sends a rejection notification to the candidate. Errors encountered during resume processing or AI evaluation are reported separately, and each run's outcome is logged for tracking purposes.

---

## Purpose

To reduce manual effort in screening job applicants by automatically extracting candidate information, evaluating fit against the job requirements using AI, and routing qualified candidates toward interview scheduling while notifying unsuccessful candidates.

## Workflow Summary

```
Receive Job Application
        │
Download & Extract Resume
        │
AI: Extract Candidate Profile
        │
Retrieve Job Details
        │
AI: Evaluate Candidate
        │
Store Candidate & Application Records
        │
Notify HR with Candidate Summary
        │
Wait for HR Decision
├── Approved → Check Interview Availability → Create Interview Event → Send Interview Invitation
└── Rejected → Send Rejection Email → Update Application Status

Errors (Resume Upload / AI Evaluation)
        │
Notify Admin → Log Failure

Every Run
        │
Log Execution Outcome
```

## Integrations

| Service | Purpose |
|----------|----------|
| Supabase | Stores candidate records, applications, job details, and execution logs |
| Google Gemini | Powers AI-based resume extraction and candidate evaluation |
| Google Drive | Retrieves submitted resume files |
| Google Calendar | Checks interview availability and creates interview events |
| Gmail | Sends interview invitations and rejection emails to candidates |
| Slack | Notifies HR of new candidates and notifies admins of processing failures |

## Inputs

- Job application submitted via webhook (POST request), including candidate details and a resume file reference

---

## Outputs

- Candidate and application records stored in the database
- HR notification containing candidate evaluation summary
- Interview invitation email with a scheduled calendar event (if approved)
- Rejection email (if not proceeding)
- Execution log entry recording the outcome of each run
- Admin notification on processing failure
